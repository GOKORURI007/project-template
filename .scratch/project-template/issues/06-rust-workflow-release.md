# 06: 打通 Rust 包检查与独立发布

**What to build:** 使用者可以在统一工作区运行最小 Rust 包的官方检查、测试和构建，并通过共享 release TUI 进行符合 Rust 元信息规则的独立本地发布。

**Blocked by:** 04: 交互式独立发布 Node 包到本地

**Status:** resolved

**Spec coverage:** User Stories 2–3, 21, 23–26, 31–32, 34–35, 37–39, 45；遵守已确认的领域术语、任务约定及相关 ADR。

- [x] 提供可独立删除的最小 Rust 示例，公共任务调用官方格式化、lint、编译检查、测试和构建命令。
- [x] 不支持自动修复的任务输出普通 info 并成功退出，明确没有执行修复；实际检查发现问题或工具缺失时失败。
- [x] 发布处理 Rust 原生版本元信息和 tag，版本继承或依赖要求有冲突时明确停止，不盲目修改共享版本或传播升级。
- [x] 发布前检查完整经过共享流程；失败时所选包版本和发布记录不变。
- [x] 通过公开命令验证原生任务、缺工具、成功发布与版本继承／依赖冲突结果，不自动安装工具链。


## Comments

使用临时隔离的官方 Rust 1.99.1 GNU 工具链，6 个公开命令测试通过：官方任务、真实 Turbo 构建、Clippy 显式修复、静态版本与真实共享锁更新、继承版本／caret 依赖冲突和缺编译器失败。未修改系统 PATH；验证工具不进入模板安装逻辑。
