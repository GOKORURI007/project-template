# 01: 运行首个 Node 工作流

**What to build:** 使用者显式准备依赖后，可以在默认 npm 工作区通过 Turbo 运行首个 Node 示例的完整检查与构建流程，并获得准确的选包结果、提示和退出码；公共能力由共享管理包提供。

**Blocked by:** None（can start immediately）

**Status:** resolved

**Spec coverage:** User Stories 1, 4–7, 18–19, 23–26, 29–32, 62；遵守已确认的领域术语、任务约定及相关 ADR。

- [x] 建立始终保留的私有 TS/JS 管理包和最小 Node 示例，语言原生工具通过公共任务入口运行。
- [x] 通过公开命令完成 format、format:check、lint、lint:fix、typecheck、test、build；检查和修复对文件的影响符合任务约定。
- [x] 全仓库缺少某任务的包被提示并跳过，显式选中的包缺少该任务时失败；必要工具缺失时明确失败且不影响其他目标单独运行。
- [x] 格式化与修复不被旧缓存跳过，确定性检查和构建按准确输入输出工作。
- [x] 用户能按说明手动准备管理运行环境与依赖，管理命令不会隐含下载或安装工具。
- [x] 在临时工作区通过公开 Turbo／管理命令验证输出、退出码和文件结果；脚本采用可移植的路径及进程调用。
