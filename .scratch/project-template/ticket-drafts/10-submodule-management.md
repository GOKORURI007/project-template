# 10: 通过共享 TUI 管理 submodule

**What to build:** 使用者通过管理包 TUI 和对应 Turbo 任务，查看、初始化、同步、更新和推送子项目中的 submodule，并清楚区分固定提交同步与上游更新。

**Blocked by:** 02: 交互式初始化项目并诊断环境

**Status:** ready-for-agent

**Spec coverage:** User Stories 46–51, 57, 62, 64；遵守已确认的领域术语、任务约定及相关 ADR。

- [ ] 利用原生 submodule 来源信息发现目标并展示状态，业务配置位于管理包源码之外。
- [ ] 初始化和固定提交同步恢复父项目记录的提交，不隐含推进到远端最新状态。
- [ ] 上游更新只作用于所选目标，并清楚展示目标 revision 与操作结果。
- [ ] 推送明确使用所选或配置的来源和目标分支，不能从当前状态确定目标时给出明确提示。
- [ ] 提供可交互的操作选择及相应可调用的 Turbo 任务，不与业务发布隐含联动。
- [ ] 通过本地父仓库、子仓库和 remote 夹具验证各操作的 Git 结果、失败输出和退出码，并说明使用方式。
