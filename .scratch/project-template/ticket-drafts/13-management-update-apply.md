# 13: 应用兼容的管理包更新并保留定制

**What to build:** 使用者审阅预览后将上游管理包变更应用到派生项目，保留自己的业务包、根配置与扩展；本地管理源码修改或配置不兼容时停止更新。

**Blocked by:** 12: 预览模板上游的管理包更新

**Status:** ready-for-agent

**Spec coverage:** User Stories 52–61, 64；遵守已确认的领域术语、任务约定及相关 ADR。

- [ ] 对确认的目标应用管理包目录新增、修改和删除，记录实际 commit 与新的可验证基线；作用范围仅为管理源码及必要更新状态。
- [ ] 发现管理源码相对基线有本地修改时停止并展示差异，不自动覆盖或合并。
- [ ] 目标不兼容现有项目配置时，在改写源码前停止并说明需要手动调整的内容。
- [ ] 业务包、业务根配置和目录外扩展保持不变，本地配置更新后仍然优先。
- [ ] 依赖变化只提示后续手动操作，绝不自动安装；环境已显式准备且配置兼容时，更新后的公开管理入口可以运行。
- [ ] 通过无共同历史的本地上游夹具验证成功更新、重复更新、保留定制、两类停止条件和无安装行为。
