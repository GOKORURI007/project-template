# 03: 切换包管理器并保留已有锁文件

**What to build:** 使用者在 turbo init 中选择 npm、Bun、pnpm 或 Yarn，得到一致的包管理器声明和工作区配置，并明确知道已有锁文件冲突和后续手动准备步骤。

**Blocked by:** 02: 交互式初始化项目并诊断环境

**Status:** ready-for-agent

**Spec coverage:** User Stories 7–8, 12–13, 16–18, 64；遵守已确认的领域术语、任务约定及相关 ADR。

- [ ] 默认 npm；四种选择更新对应声明和工作区配置，保留原有工作区包的选择范围。
- [ ] 已有锁文件保持内容与存在状态不变，不自动转换、删除或生成替代锁文件。
- [ ] 冲突与后续手动操作在交互结果中可见，不安装依赖、包管理器或其他工具。
- [ ] 重复选择同一管理器不重置用户配置，切换不改写各语言包名称和版本。
- [ ] 通过公开初始化命令验证四种配置结果、重复执行、锁文件保留及禁止安装行为；用户按说明显式准备后可继续运行已有任务。
