# 12: 预览模板上游的管理包更新

**What to build:** 使用者显式运行 turbo manager:update，配置同一模板上游及分支或 tag，查看仅管理包目录的差异、来源 commit 和需要手动完成的后续操作。

**Blocked by:** 02: 交互式初始化项目并诊断环境

**Status:** ready-for-agent

**Spec coverage:** User Stories 52–57, 60–61, 64；遵守已确认的领域术语、任务约定及相关 ADR。

- [ ] 支持没有共同 Git 历史的模板复制项目，不要求额外管理仓库、registry 包或 subtree 分发分支。
- [ ] 从配置来源获取指定管理包目录，确定可验证的旧基线与目标 commit；不能把无法验证的当前源码直接视为可信基线。
- [ ] 预览新增、修改和删除等目录差异，以及依赖或环境需要手动准备的变化。
- [ ] 预览不改写业务包、业务根配置或当前管理源码，来源和更新状态位于可更新管理源码之外。
- [ ] 只有显式命令会检查更新，不自动安装依赖或工具。
- [ ] 通过本地模板上游和无共同历史的派生项目验证来源选择、目录限定、commit／基线和预览结果。
