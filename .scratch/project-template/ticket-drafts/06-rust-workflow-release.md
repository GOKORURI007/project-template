# 06: 打通 Rust 包检查与独立发布

**What to build:** 使用者可以在统一工作区运行最小 Rust 包的官方检查、测试和构建，并通过共享 release TUI 进行符合 Rust 元信息规则的独立本地发布。

**Blocked by:** 04: 交互式独立发布 Node 包到本地

**Status:** ready-for-agent

**Spec coverage:** User Stories 2–3, 21, 23–26, 31–32, 34–35, 37–39, 45；遵守已确认的领域术语、任务约定及相关 ADR。

- [ ] 提供可独立删除的最小 Rust 示例，公共任务调用官方格式化、lint、编译检查、测试和构建命令。
- [ ] 不支持自动修复的任务输出普通 info 并成功退出，明确没有执行修复；实际检查发现问题或工具缺失时失败。
- [ ] 发布处理 Rust 原生版本元信息和 tag，版本继承或依赖要求有冲突时明确停止，不盲目修改共享版本或传播升级。
- [ ] 发布前检查完整经过共享流程；失败时所选包版本和发布记录不变。
- [ ] 通过公开命令验证原生任务、缺工具、成功发布与版本继承／依赖冲突结果，不自动安装工具链。
