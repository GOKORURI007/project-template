# 从模板上游单独更新管理包目录

通过复制模板创建的项目也需要获得公共管理能力的更新，因此 `turbo manager:update` 从同一个模板上游仓库获取指定管理包目录，来源和分支/tag 可配置，并记录实际使用的 commit。相比依赖共同 Git 历史、额外的 subtree 分发分支或 registry 发布，这一方式兼容模板复制后的独立仓库，同时需要记录可验证的上游基线来检查本地源码修改。

项目配置和扩展位于管理包目录外，本地配置优先。更新前预览差异和后续手动操作；发现管理包源码有本地修改或新版本不兼容现有配置时停止，不覆盖定制。更新只在使用者显式执行时检查，不自动安装依赖，也不覆盖业务包或业务根配置。
