# 用共享管理包承载跨语言管理能力

模板始终包含一个使用 TypeScript/JavaScript 的管理包，集中提供初始化、发布和 submodule/subtree 管理，`init`、`release` 与外部源码管理的 TUI 均由它实现。各语言包提供其原生任务入口与适配所需的信息，共享管理包处理公共交互和流程。相比为每种语言维护独立管理脚本，这一边界避免交互、错误处理和 Git 操作随语言数量重复实现；管理包的运行环境也成为这些公共能力的统一前提。

管理包默认不参与业务包发布。模板上游更新管理包后，派生项目可以单独获取这部分更新，具体边界见 [ADR-0005](0005-directory-scoped-management-updates.md)。
