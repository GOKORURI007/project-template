# 模板初始化只配置与诊断，不安装工具

模板使用者需要通过 `turbo init` 修改项目名称等身份信息，并选择 npm、Bun 等包管理器。初始化负责更新模板配置和报告环境适配状态；它绝不自动安装语言工具链或项目依赖。与把初始化做成完整环境安装器相比，这一边界让使用者保留环境管理权，也避免切换配置时隐含触发安装；缺失条件由使用者自行补齐。

支持 npm、Bun、pnpm、Yarn，默认 npm。切换时更新声明和相应工作区配置，保留已有锁文件，提示锁文件冲突及需要使用者手动完成的操作；不自动转换或删除锁文件。

项目名称、简介、作者等项目元信息同步到根 `package.json` 和 `apm.yml`，各语言包保留独立名称与版本。重复运行时展示当前值，只修改使用者确认的字段。
